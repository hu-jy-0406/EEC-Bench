# Gs_global 原相机视角的重投影框误差

冻结三种方法的最终融合Gs_global，不重新拟合、不调相机。使用相同独立静止划分和所有可见实体帧，包括融合时被舍弃的帧及低支持框。

主指标为1−IoU；先对每个实体的可见帧平均，再对shot内实体平均，最后两个shot等权。

| 方法 | Shot1平均IoU↑ | Shot3平均IoU↑ | 两shot平均IoU↑ | 1−IoU↓ | 边界RMSE(px)↓ | 中心偏差(px)↓ |
|---|---:|---:|---:|---:|---:|---:|
| Codex 直接3D | 0.4556 | 0.5284 | 0.4920 | 0.5080 | 26.36 | 22.10 |
| Codex相机 + Boxer | 0.5247 | 0.5462 | 0.5355 | 0.4645 | 24.22 | 19.88 |
| GeoCalib + Boxer | 0.5429 | 0.6130 | 0.5779 | 0.4221 | 23.79 | 19.26 |

**主指标最优：GeoCalib + Boxer。**

三维框8个角点由中心/尺寸/旋转重新计算，以各自相机R、位置和K投影；取2D包围框，裁切至852×480图像范围后与冻结2D框比较。边界RMSE为四个xyxy坐标差的均方根，中心偏差为两框中心的欧氏距离。还记录除以目标框对角线的归一化误差。不是具备真实角点对应的经典重投影误差。

样本：Shot1的17个静止实体、96个可见实体帧；Shot3的21个静止实体、125个可见实体帧。每种方法共221个，三种方法共663项，逐项样本键完全一致。缺失/无效/相机后方投影计IoU=0，边界及中心误差按图像对角线惩罚；本次实际无效数量见summary.json。

结论范围：这是对现有2D框的样本内拟合比较。2D框是Boxer输入，且融合权重也使用了投影IoU；不是独立留出测试、人工真值或3D精度评估。遮挡时完整3D物体包络与可见2D框的语义也可能不同。三种方法使用各自原相机，因此比较的是相机+几何组合，不能单独归因于几何生成器。

## 指标差别与验证

GeoCalib+Boxer在两个shot的平均IoU均最高，整体边界RMSE和中心偏差也最低。但Shot1的Codex相机+Boxer边界RMSE为27.33px、中心偏差22.43px，略好于GeoCalib+Boxer的27.82px和22.73px。不能说每个shot的每个指标都由第三种方法胜出。按实体IoU比较，38个实体中Codex/Boxer+Codex/Boxer+GeoCalib分别赢13/8/17个，无平局。

本次汇总用均值；此前六图summary中的“逐实体中位数再取中位数”是不同统计口径，不能直接对照数值。所有观察等权、所有实体等权两种补充口径也都由GeoCalib+Boxer整体最好。

6项行为测试通过；663项IoU用另一投影函数独立复算一致；每方法221个样本、源文件哈希不变、无无效投影，见audit.json。浏览器交互未实测。
