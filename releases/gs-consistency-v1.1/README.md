# Gs consistency v1.1

主分数只扣确认冲突：100 × (1 − K/(C+K+U))。互补 V 不进入分母；未知 U 不扣分、通过覆盖率和区间表达。主分数是乐观上界，不是证实一致率。全部未知则不可判定。

源码依赖闭包、三份提示词、测试、真实 Gs 输入、四个阶段的证据和计分/审计结果均已按 SHA256 固定。几何前端引用另一个固定版本 static-geometry-20260914-v1。匹配与两次盲审核后，仅允许一次针对弃权分歧的候选证据回查。

本例88.89分、覆盖22.2%，C=2,K=2,U=14,V=7。台灯/纸巾冲突被确认；杯子与笔筒互换尚未可靠检出。本例不是多场景准确率或阈值标定。每次模型调用原始证据均保留，不能把模型同意视作真值。

可在计算节点从冻结副本确定性重放评分，不产生新的模型调用。详细设计见 payload/EECBench/docs/gs-consistency-v1.md。
