# Witnessed Static Consistency (WSC), v1.1

目标：在同一场景、要求静态布置延续的两个 shot 之间，测量有观测证据支持的 Gs_global 冲突。**图中缺失不等于物理不存在。** 相机改变、视野互补、遮挡、检测遗漏以及不可靠的单目深度，均不能仅凭图差异扣分。

## 固定前端

`EECBench/releases/static-geometry-20260914-v1` 保存三种现有生成方法、独立逐 shot 动静划分、质量融合和二维重投影评测的代码/提示词/数据快照与 SHA256。首选 `boxer_geocalib`，选择依据仅是当前同样本重投影 IoU。评分不改写 Gs、不重新划分动静实体、不以跨 shot 一致性反向优化物体位置。每个 shot 的动静分类仍隔离进行；之后的跨 shot 比较阶段才允许同时看两者。

原前端限于这次固定机位实验。相机平移为零、模型尺度先验、3D 框深度误差等限制保留，不能把此版本宣称为已支持移动相机的通用几何生成器。评分接口本身接收每帧独立相机记录。

## 处理流程

1. **Gs 为输入骨架。** 保留所有静态实体的 OBB、相机、逐帧 2D 框、几何支持度、MAD 和重投影诊断。实体名称仅作线索。原始帧按哈希检查后附给模型，提示词不含数据目录、预期异常标签或历史异常判断。
2. **固定实体对应单位。** 一个新上下文输出覆盖全部节点的对应分区：matched（严格一对一）、unmatched（单侧单节点）、ambiguous、scope_mismatch。后一阶段不能为提高分数删实体或改匹配。歧义组保留 `max(|A|,|B|)` 权重；其余单位权重为 1。不是文本同名匹配，也不是原始坐标最近邻。
3. **3D 候选诊断。** 只在身份明确、可作稳定结构参考、且几何支持尚可的锚点上，枚举三锚点的 proper Sim(3)：`X_b = s R X_a + t`, `s>0`, `det(R)=+1`。拒绝共线退化。以目标锚点间距离中位数归一化残差；保留最优损失 +0.10 内的假设。至少四个锚点、最优归一化损失 ≤0.15 才标为 trusted。此阈值是版本化启发式，不是校准置信区间。被测实体不能参与其测试所用的锚点集合。输出注册位移范围与成对距离差异，绝不直接把残差变成扣分。
4. **局部反事实取证。** 对每个实体单位都询问“同一未改变的空间占位，能否解释两个 shot？”全局配准不可靠时，可以核查局部支撑/建筑区域，但必须明确至少两个已对应且不含被测实体的地标、方向/映射依据，以及排除其他映射的理由。不能以对称桌面或图像左右定义唯一世界方向。
5. **两个新上下文独立审核。** 两次收到相同 Gs、候选对应、几何诊断和全部原帧；第二次看不到第一次结论。每个结论保存原图 frame ID、XYXY 证据区域、3D 依据、反事实位置、替代解释和七个门控声明。两个同模型调用的同意只是审核条件，不是统计独立证据。
6. **最多一次证据回查。** 仅当一个审核给出通过门控的相容/冲突、另一审核弃权时，向新上下文提供两者的候选位置、区域和反事实问题（不提供判决标签）。要求重新核查原始帧，可以继续弃权。只有原有正面判断与回查共同通过同样门控才解决分歧。相容与冲突直接对立时不能靠回查多数票解决。没有循环重试。
7. **确定性门控和计分。** 代码检查节点覆盖、证据帧/框是否合法、独立帧数、锚点循环、配准可信条件、两次机制/参考地标是否相容。任一缺失、分歧或门控失败降为 unknown。所有分项结论、门控原因和原始模型响应可重放。

## 四类结果

- **compatible（C）**：共同实体的存在和空间位置/范围有正面的相容证据，至少两边各一帧。仅“都看到了同名物体”不够。
- **complement（V）**：单侧实体所在区域/必要诊断部位在另一 shot 可证实地处于视野外或被遮挡。不是因为节点缺失就标为互补。互补既不扣分，也不作为奖励扩大分母。
- **conflict（K）**：无法由合理视角、遮挡、检测遗漏、几何误差或替代配准解释的占位/位置/形状冲突。
- **unknown（U）**：不足以证明相容、互补或冲突。unknown 不扣分，也不当作已证实一致。

存在冲突用双向同规则检查。若源实体未改变，则一个明确诊断部位应在目标的至少两张不同帧中可见，而指定位置却为空或不相容；至少引用一张源帧。该结论只是“旧位置的占位不延续”，不声称整个房间没有该物体。图中漏检、目标处于遮挡后等情况不能扣分。

共同实体位置/形状冲突要求两边各至少两张不同帧、明确的独立空间参考，以及对深度误差和备选轴映射的排除。两物体互换可能保持它们之间的距离，所以要检查它们各自相对于稳定参考的占位，而不是只看两者距离或图像顺序。

冲突七门：身份支持、映射支持、区域可观察、几何误差替代解释排除、遮挡排除、检测遗漏排除、其他合理映射排除。门控依赖可审计的视觉模型证据，不是从 JSON 布尔值获得数学上的物理证明。七门全部为真仅用于确认冲突；相容允许残留尺度/深度误差，只要有独立映射、可观察区域与正面的相容占位证据。相容并不证明所有隐藏几何完全相同。

## 分数与覆盖率

\[
\mathrm{WSC}=100\left(1-\frac{K}{C+K+U}\right),\qquad
\mathrm{Coverage}=\frac{C+K}{C+K+U}.
\]

C、K、U、V 是固定实体单位的权重总和。**主分数是仅扣确认冲突后的乐观上界，不是已证实一致率。** 未知项不扣分；从相容变成未知不能放大已有冲突的罚分。一个物体即使破坏许多关系，也只计一次冲突；两个实体都改变位置各计一次。V 完全不参与分子和分母，所以增加视野互补不会稀释已有冲突。

`C+K=0` 时返回 `score: null`，不返回虚假的 100。分数必须连同 coverage 报告；不同覆盖率下不能只按分数排名。另存 `conditional_assessed_score=100C/(C+K)` 仅供诊断，不作主分数，因为该条件分数会在只确认一个冲突时变成 0，即使其余全部未知。未知项扩大下面的逻辑敏感性区间：

\[
[100C/(C+K+U),\ 100(C+U)/(C+K+U)].
\]

区间表示如果所有未知项最终都冲突/都相容，非互补部分的可能分数范围；**不是统计置信区间**。全互补、没有共同可检验区域时，分数/覆盖率/区间均为 null。

例如，5 个有证据相容实体、2 个冲突、3 个 unknown、任意多个互补，WSC 为 80，覆盖率 70%，区间 [50,80]；条件诊断分数为 71.43。加入更多互补不改变这些值。

## 使用

在符合项目 CPU/Slurm 安全规则的计算节点执行：

```bash
python EECBench/scripts/freeze_static_geometry_pipeline.py --verify EECBench/releases/static-geometry-20260914-v1
python EECBench/scripts/run_gs_consistency.py \
  --graph-a /absolute/path/to/shot_a/Gs_global.json \
  --graph-b /absolute/path/to/shot_b/Gs_global.json \
  --source-a /absolute/path/to/shot_a/source_shot.json \
  --source-b /absolute/path/to/shot_b/source_shot.json \
  --out /absolute/path/to/new_run
```

source_shot.json 是当前单 shot 数据封装（`shots[0].calibration.images` 包含原图 path/hash/frame_id）。每个 Gs 使用三方法融合输出结构；新的数据适配器需保留同样的实体/相机/帧证据契约。当前入口不直接消费任意裸 3D 点云。

已成功调用的阶段可用 `--resume` 复用；输入和模型配置必须完全相同。不会静默重试失败模型调用。确定性重放评分无需模型或图片上传：

```bash
python EECBench/scripts/score_gs_consistency.py /absolute/path/to/run
```

输出 `score.json`、逐项 `report.html`/`README.md`、Gs 输入快照、匹配、数值诊断、模型提示词/响应/调用审计和代码哈希。

## 验证边界

程序控制测试检查分数的互补不变性、相容变未知不放大罚分、unknown 不作为已证实一致、相机坐标变换、反射拒绝、双向对称、遮挡/歧义门控、同一实体不按关系重复计数等。它们验证实现规则，不能替代真实图像上的召回率和误报率测试。初版 run01 保留条件分数的退化结果；run02 的 v1.1 根据“不因看不清放大罚分”这一通用性质修正主公式，并增加一次证据检索回查。物体名和用户预期异常没有写入规则。本例是初次端到端测量，不能据此调整规则到命中给定答案，也不能声称指标已经过多场景标定。
