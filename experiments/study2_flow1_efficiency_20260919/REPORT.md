# Flow1 skill 与传输效率优化

## 已采用的结果

流程1继续作为默认，流程2保留。压缩已启用于初始matching、对齐后identity_review、presence_1/2；空间模型阶段保持原传输。初始配对一轮、A复核+B两轮均通过；第二轮使用正式入口串行传递优化后的身份结果。38实体身份、参照、全部28个B组分类与计分均不变。全部28个空间对cosine也不变（6负值）；空间模型复核未重跑。

优化阶段合计（初始配对实测一次，A+B取两次平均）：token 705,964→340,614，减少51.75%；调用关键路径时间 807.56s→737.39s，减少8.69%。不含检测、建图、GPU配准和空间模型阶段，不是整条视频评测的端到端加速。身份复核本身耗时未降低，时间收益主要来自初配对与B。


## 固定的处理逻辑

完整初始身份对应+A′ → 原结构区域配准 → 逐组对齐后身份复核 → 两次独立存在性B → 原空间评测。模型继续gpt-6-astra/medium，原JPEG、实体清单、输出schema、Prompt因果复核、共识门槛和评分不变。流程2作为独立备选保留，不默认启用。

## 实现

- 去除反复书写的字段名：同结构行使用列名+行值；重复子结构使用共享引用。
- 保留中心、尺寸、旋转的原始精度；只有原八角点可由这三者恢复、误差≤1e-9时才使用角点派生标记，否则原样发送。实际最大误差1.3323e-15。完整原角点仍留在canonical input和数值计算中。
- 原判断提示词完整保留，附加格式说明与简洁表达要求；没有删除原输出字段、证据或判断阶段。
- 新skill和阶段入口集中管理传输配置。数字运算、共识和评分方法与原版AST一致。空间模型调用的传输暂不变。

## 验证设计

首轮：压缩初始对应、A复核与两次B分别用固定历史输入对照；次轮：正式入口读取首轮压缩初始配对，重新执行压缩A复核，再让该输出直接进入两次B。两轮共7次新调用，无检测/深度/配准重跑。

质量门槛：全部通过。检查全部38实体身份/分组、参照选择、28个B组分类与分数、图像哈希、角点重建误差、全部28个空间对的cosine。空间模型取证及最终复核未重跑；其传输逻辑未改。
