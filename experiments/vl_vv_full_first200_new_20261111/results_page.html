C、C + 插件、new、new + 插件：unspecified 实体指标与分数

前 200 个 episode × 5 个模型，共 1,000 个视频，四个版本都跑完了全部视频。下面先看 unspecified（未指定）实体的数量、相关问题和出问题的比例，再看分数和费用。

  • 未指定实体占全部实体：22.4% → 24.0% → 27.5% → 28.9%。new 的实体范围更大（穿戴物品、墙地面等也算实体），所以台账更大，未指定占比也更高。
  • 确认的 V-V 问题里涉及未指定实体的比例：3.75% → 8.19% → 10.50% → 24.24%。V-L 问题四版都是 0 条涉及未指定实体，因为 V-L 只查 contract 写到的实体。
  • 出问题的比例（作为确认 V-V 问题的主体）：指定实体 12.8% / 12.9% / 10.9% / 10.6%，未指定实体 3.3% / 6.7% / 4.8% / 11.2%。只有 new + 插件里未指定实体出问题的比例超过了指定实体。
  • 独立运行一版的费用（标准价估算）：USD 78.93 / 89.00 / 90.55 / 106.77。UEC 平均分 81.54 / 81.47 / 82.01 / 81.61，四版的模型排序相同。
  • 所有问题都是模型确认的结果，没有人工核查。

注意事项

  • 所有问题数和比例都是模型确认的结果，没有人工核查，也不是人工标注的召回率或准确率。
  • C 和 new 的 contract 不同：new 把穿戴物品和场所部件（墙、地面、地毯、树等）算作实体，并且只在镜头文字提到它们时才列为该镜头应出现的实体。所以两组的实体数、未指定占比和分数差别包含了这一变化。
  • 插件版会把全部 V-V 候选重新复核一遍，复核本身有随机性（C 那次约 22% 相同分组的单元判定不同）。基础版和插件版之间不大的分数变化在这个波动范围内。
  • new 两版用 OpenRouter 运行，冻结代码快照在 vl_vv_full_first200_new_20261111/code；C 两版用 vl_vv_full_first200_c_20261110 的冻结代码。
