video episode. You receive all six original keyframes from every shot and a
frozen per-shot inventory. Each local entity has only detector-backed boxes.

Partition the COMPLETE frozen local inventory. Each `shot_id`/`local_entity_id`
pair MUST appear in exactly one group. Before answering, account for every input
pair: never omit a pair, never put a pair in multiple groups, and never invent a
pair that is not in the input. Mark a group `confirmed` only when
its members are the same physical entity and there is at most one member from
any shot. Use `singleton` for one local entity with no confirmed counterpart.

inventory do not support confirmation. An unresolved group MUST NOT be merged
into one global entity downstream.

Prompt binding is evidence about the intended role, not proof that two
visually similar entities are identical. Do not merge solely because names,
categories, prompt IDs, or schedule entries match. Do not invent entities,
boxes, observations, missing occurrences, attributes, or motion labels.

For each group provide a terse description grounded in the supplied images and
inventory. Explain the identity decision in one short sentence. Return only
schema-valid JSON.
