**实现完成，但目前不建议替换生产默认版。** 全三维配准能运行且固定点对照残差下降；去GeoCalib后的整套流程没有保持Study2/3旧版空间冲突的确认结果。现有实验分支供后续比较，原默认保持不变。

入口：`--alignment-method roma_fps32_free3d --runtime-profile gravity_free_v1`。回到默认 `roma_fps32` 与当前生产runtime即恢复旧版。外观与prompt alignment代码可沿完整分支继续执行，但本次没有实际重跑这两个无关评分模块。

完整机器可读结果：`results_comparison.json`；逐次请求、原图证据、unknown原因与费用见各 `corrected/study*/run`。

## 实现

- Pi3X 保留原生坐标，不加载 GeoCalib 权重或预测；实验指定了不存在的 GeoCalib 权重路径。
- 配准从重力轴 yaw 改为完整 SO(3) 旋转，保留 FPS32、0.2置信度阈值、正尺度范围和所有选中点的无权重、非平方欧式距离之和。
- 跨 shot Codex 空间复核改为相同支撑面/可对应参照特征上的相对几何证据。保留独立单 shot 观察、全部原图、端点及至少两帧见证、身份/遮挡/中心语义/Prompt/共同存在约束。负 cosine 只提名候选。
- 修正另外发现的 Boxer 隐含依赖：其 `encode` 默认使用世界 Z 为重力。新适配器显式给出相机局部推理参考系，绕过该行为，权重不变。这个参考系不是物理向上估计；由于模型训练使用重力对齐参考系，不能假设输出质量完全不变。
- 镜头内检查、位移公式、空间分母不变。完整 pipeline 可选择新分支；本次实际运行范围为原始帧→检测/三维/身份/存在/空间/位移，没有重跑无关的 appearance 和 prompt alignment。

## 首次尝试的排查记录（不计为最终验证）

`study2/run` 直接把原生坐标输入默认 Boxer，暴露其世界 Z 隐含假设。Pi3X 原始相机/内参/深度与旧版逐值相同，但96个相同二维框的中心在恢复旧坐标后平均差0.51348、最大2.64613。修正后的相机参考系在同一 Shot1 上对应差异降为0.07083/0.51569；这不是准确率或真实测量误差，只是相对旧版的输出差异。

首次尝试完成记录：891.30秒，729,098 tokens，估算标准 API 等价 **USD 8.527980**；无最终空间冲突。该运行保留用于解释修改原因，不与正式三组结果混用。修正前后的源文件快照分开保存。
