前 200 条评测：分数与 unspecified 实体指标

200 个 episode × 5 个视频生成模型，共 1,000 个视频，全部评测成功。评估器为 chain v6（GPT-6 Luna，reasoning low）。V-V 检测按 checklist 逐条调用（每个视频 17 次）；墙面、地面、天花板算作所在场景（地点）的一部分。每个视频评测一次，结果未与人工评分校准。

要点

13.8%
检测到的实体中 unspecified 实体的占比（2,335 / 16,869）；在 ≥2 个镜头出现的实体中只占 3.3%（278 个）
1.8%

12.6% vs 1.1%

结论：unspecified 实体本身并不少，但绝大多数只在一个镜头里出现，而一致性（V-V）问题大多要求同一实体出现在多个镜头里，所以涉及它们的问题很少。按实体计，specified 实体出问题的比例约为 unspecified 的 11 倍。

与旧版对比（同一批 668 个视频）

这 668 个视频沿用 11 月 7 日首次运行的检测前端和 V-L 结果，只重跑了 V-V 检测、V-V 复核和评分，所以两版的实体完全相同，差别只来自 V-V 部分的改动（逐条 checklist、墙面算作场景）。首次运行停下时只完成了这 668 个视频，另外 332 个视频没有旧版结果，所以对比只在 668 个视频上做。新版在这 668 个视频上的占比是 1.6%（31 / 1,993），另外 332 个视频是 2.2%（21 / 942），合起来就是上文全部 1,000 个视频的 1.8%（52 / 2,935）。

旧版的 4.1% 是怎么来的

  • 旧版 42 个问题全部是评估 agent 新建的实体（n…），其中 21 个是墙面、地面、墙砖之类，其余多是窗框、卡座、橱柜等背景部件。
  • 这 21 个墙面/地面问题在新版中：12 个被确认、主语改为合同里的地点（specified）；4 个归到其他合同实体（池壁、窗户、搁架、窗帘）；5 个没有被确认。
  • 检测器（WeDetect）在这些视频的全部关键帧中没有输出过任何墙、地面、天花板候选框；12 个地点里有 9 个的合同描述本身就写了墙面或地面（例如 “walls covered with pale patterned wallpaper”）。
  • 上限估计：新版中主语只有地点的场景背景问题共 85 个；即使全部算作 unspecified，占比最多约 4.7%（137 / 2,935）。

每个模型 200 个视频。V-L：视频与 prompt 合同是否一致；V-V：视频内部（镜头内、跨镜头）是否一致；V-V 为镜头内与跨镜头的平均，UEC 为 V-L、V-V 镜头内、V-V 跨镜头三项的平均。评分公式（2026-11-09 起为默认）：每个问题扣分 D = 严重度权重（10 / 25 / 50 / 80）× 置信度系数（确认且置信度高 / 中 / 低为 1 / 0.75 / 0.5，不确定为 0.25，否决为 0）；每个维度 s = 100·exp(−ΣD / (100·S))，S 为该 episode 的镜头数，按镜头数归一以免长 episode 吃亏。

运行信息与说明

  • 运行时间：2026-11-09 16:23–20:02（迪拜时间），1,000 / 1,000 成功。668 个视频复用 11 月 7 日的检测前端和 V-L 结果；332 个视频完整重跑（134 个前端在 CPU 上，198 个在 GPU 上）。
  • 本次新调用：25,124 次模型调用，输入 672.5M token（其中缓存 305.4M），输出 13.1M token，约 46.32 美元（GPT-6 Luna 标准 API 价格估算，不是账单）。
  • 局限：每个视频只评测一次，未测运行间波动；结果未经人工校准；specified / unspecified 标签来自实体账本（是否对应合同实体），不是逐条人工判断。
