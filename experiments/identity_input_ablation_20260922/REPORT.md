# 配准后身份复核：输入消融实验

推荐候选：**仅对齐中心与尺寸**（`lean_geometry_only`）。完整结论见下列质量边界；不声称模型输出绝对确定，不修改生产默认。

## 实验范围

- 固定 Study2/3/4 的旧版 GeoCalib 检测、聚类、初始匹配和配准；仅重新调用身份复核。保持 Astra/medium、原始图片、完整实体范围、focused 身份输出和原校验规则。
- 每组均提供 Shot1/Shot3 各6张原始帧，图片字节与分辨率完全不变。原始 canonical 输入、配准和评分几何未修改。没有重跑 GPU 前端，也没有把这些调用当作完整 pipeline 时长。
- 先做输入块单项删除，再做组合与更小边界探测；完整输入重复对照。最终候选每组3次。选择查看全部试验，未删除失败/不一致结果。
- 完整输入在 Study2/3 重复时也出现同一植物关联的 ambiguous/unmatched 波动；因此单项删减差异不能自动解释为因果性退化。没有人工身份真值，历史模型结果只作回归参照。

Study3 用于候选筛选，三组均为开发期固定测例；重复调用不是新增独立 episode，没有独立人工标注测试集。

## 为什么推荐这一档

- 中心/尺寸版是完成三组各三次验证的方案中输入最小的一档；全部确认身份、锚点与参考一致，所有完整分组都在同测例完整输入对照出现过的范围内。
- 7/9次与历史单次分组完全一致；两次差异都是 Study2 边桌植物的 ambiguous/unmatched 表达。完整输入对照本身4/6次与历史分组一致，也有相同不确定项波动；不声称两者分布相同。
- 较大的短轨迹版8/9次完全一致，仍有相同波动；更精简的短轨迹版7/9次。样本不足以证明细微差异是质量提升，因此没有用额外轨迹换取未经证明的保证。
- 更小的无3D/无2D/无初始解释方案没有获得同等级别的稳定性证据。删除情节的一次调用违反keep操作的原group-ID约束，不能据此证明情节一定必要，但该候选未通过原协议。
- 这是有限开发测例上的最简实测建议，不是全输出等价或普遍质量保证；如果要求所有不确定身份及下游分数零变化，本实验没有证明任何精简版本满足。

## 推荐候选的重复验证

- 9/9次保留全部确认匹配、锚点资格、锚点选择和参考实体；完整身份分组 7/9 次与历史参照一致。
- 9/9次完整分组均落在对应测例完整输入对照实际出现过的分组集合内。这个有限样本检查不能证明分布相同、统计非劣或普遍正确。
- 9/9次原帧见证合法，确认匹配/拆分具备双侧见证；没有新增/丢失实体、运动重分类、坐标修改或图片降质。
- 已重新计算冻结精确端点的全部 cosine 和中心距离：评测对及数值均一致。这个检查不是重新运行后续 VLM 评分；不能据此宣称所有后续模型判定/得分完全相同。

## 费用与可复现性

本任务全部 57 次请求（含失败、对照和重复）：**2,986,146 tokens / USD 39.673500 标准 API 等价估算**，不是实际账单。
费率按项目记录的 Astra USD/百万tokens：未缓存输入10、缓存输入1、输出50；缓存为输入子集，未重复计数。本实验请求低于272k输入门槛。实际 usage 保存于每次 calls/identity_review/status.json；生产候选成本与本次研发验证总费用分开。
- `calls.csv`：全部请求的tokens、缓存、输出、耗时及费用。
- `evidence_audit.json`：原帧字节和双侧见证检查。
- `downstream_audit.json`：冻结几何下逐实体对/位移/存在性人口检查。
- `selected_numeric_audit.json`、最终9次`numeric_replay.json`：原始cosine、中心距离、r_e及实体分数均保存，9/9次原始r_e与冻结基线一致。
- `runs/`：每个方案和重复的 canonical/ablation/wire 输入、prompt、图片列表、原始响应、校验、用量及差异。
- `minimal_inputs/`：可审阅、可复用的三组最终建议输入；`candidate_inputs/`保留原导出副本。
- 输入契约：`../../docs/identity-review-minimal-input-v1.md`；导出器：`../../scripts/gs_identity_review_minimal_input.py`。
- `PLAN.md`、各批次计划/状态、`source_snapshot/`：实验设计和版本记录。
