## 文件与生成顺序

- `core_100.jsonl`：第一优先级，先生成这 100 条。
- `stage2_additional_100.jsonl`：第二优先级，仅新增 100 条。
- `priority_200.jsonl`：前两个阶段的累计评测集；不能把它当第二阶段的新增任务，否则会重复生成核心集。
- `stage3_remaining_200.jsonl`：第三优先级，剩余 200 条。
- `generation_queue_400.jsonl`：唯一总队列，前 100 / 200 行分别严格等于上述累计集合。
- 同名 `.ids.txt`：只有 episode_id 的清单。
- `ranking.csv` / `ranking.jsonl`：每条的队列位置、阶段、分项分数、场景证据和排序依据；不向原始 prompt 注入额外字段。
- `selection_manifest.json`：分层配额、源文件和输出哈希、逐条哈希及调度约定。
- `review.html`：可按核心 100 / 累计 200 / 全集切换，展开查看原始 prompt 和源片段链接。

Wan2.2、HoloCine、StoryMem 使用同一份 episode 队列和子集定义。优先完成三个模型共同的核心 100 条，再扩大共同评测集。各模型的阶段完成状态独立记录；失败保留并重试，不以更快完成的其他样本静默替换。

每连续 20 条都精确保留 12 / 6 / 2 的 shot-count 分布及每个数据源 6 / 3 / 1 的联合配比，便于更小批次调度。在每个阶段、每个来源×长度层内按分数递减。**派发顺序不等于完成顺序**：长视频更慢，正式报告某个子集时需要确认该集合完整，而不是取最先完成的若干视频。

## 筛选规则

这是生成前的可复现优先级选择，不是随机抽样；没有读取任何候选视频的模型生成结果或评测分数来筛选。分数是针对当前 benchmark 的工程启发式，不是经过校准的质量分、难度分或 unbound 概率。

硬约束：

1. 来源×shot 数的六个分层配额精确匹配全集；时长分布随之精确匹配。
2. Core100 每个来源作品最多一条；Priority200 每个来源作品最多两条。第二次选同一作品另有 8 分的多样性代价，优先增加不同作品。
3. 保留风格构成：Core100 为真人叙事 86 / 动画 12 / 纪录片 2；Priority200 为 173 / 24 / 3；全集为 345 / 48 / 7。稀少风格采用整数近似配额，具体六层配额见脚本和 manifest。

在约束下，用小型最小费用流优化以下代理分数：

| 项目 | 上限 | 依据 |
|---|---:|---|
| 同场景跨 shot | 50 | 已确认场景内相邻出现次数、最大同场景占比、已确认场景覆盖 |
| 环境补全机会 | 20 | 场景类型的物件丰富度，加实际 prompt 中能展示环境的取景线索 |
| 空间可观察性 | 15 | 中／广景、布局支撑物、不同观察方向的文本线索 |
| 实体复现 | 10 | 已有源实体跨同场景复现，以及相邻同场景 prompt ID 交集 |
| 取景适合度 | 5 | 减少全部局限于脸部或极近细节的测例 |

高强度动作、屏幕内虚拟内容及大量主要源实体有额外降权。屏幕内游戏占至少一半 shots 的案例明显降权，避免把平面屏幕内的虚拟场景误当作同一物理 3D 场景的强证据。没有修改任何检测、身份匹配、几何或打分规则。具体公式、正则词表和 tie-break 均保存在 `select_priority.py`。

“环境补全机会”只表示办公室、厨房、商店、带物件的生活场景等可能自然出现未列尽的细节，并结合是否有展示环境的取景；**prompt 已经写明的桌椅、灯具、植物等依然属于 prompt-bound 内容**。不把缺少 source entity ID 当成 unbound，不额外删减或补写 prompt 来诱导模型。最终 unbound 数量只能在生成后用正式 binding 流程确认。

## 筛选结果

| 指标 | Core100 | Priority200 | Full400 |
|---|---:|---:|---:|
| 所有 shots 属于一个已确认场景 | 89 / 100 | 157 / 200 | 192 / 400 |
| 不同来源作品数（现有 source_work_key） | 100 | 152 | 192 |
| 同场景转接比例的逐 episode 平均 | 97.29% | 94.25% | 78.13% |
| 实际 prompt 中环境取景线索占比的逐 episode 平均 | 38.04% | 30.65% | 24.28% |
| 平均已有源实体数 | 4.220 | 4.215 | 4.533 |

全部 400 条本来就至少含一组“已确认场景内 ≥2 shots”；筛选主要提高了同场景复现的密度。转接比例按每个已确认场景的有序出现计算 `sum(k_scene - 1)/(shot_count - 1)`，包含 A–B–A 中 A 的复现，不等同于只统计时间上紧挨的剪辑边界。

保留自然场景、车辆、动画及纪录片，而非全部集中在室内对话。核心集的单场景偏好是用户指定的评测适配取向，不能将它声称为对 Full400 内容类别的无偏估计。

内容复核实例：

- 窗边办公室进入与交谈、卧室和梳妆台、五金店柜台：有可复现的环境及人物位置，适合空间／外观／绑定评测；原文明确列举的物件不算 unbound。
- 动画披萨店：保留动画、室外、出入与取景变化，避免全部成为静坐面部交流。
- 林地露营进食：保留自然环境、物件交互、放置和离场。已明确要求的锅、刀等仍是 bound；有一个位置未确认的 shot 不擅自与其他场景合并。
- 蓝光动画客厅八 shot：保留八 shot 动画覆盖；前面有细节插入，后五个客厅镜头提供共同空间，故承认其单场景密度较低。
- 街机游戏八 shot：虽然源场景标为同一个街机空间，但四个镜头描绘屏幕内游戏，降到第二阶段；原数据保留。
- 个别纯色、暗光、强近景或多场景案例仍保留在扩展集，用于覆盖更难的观察条件。

这是对文本和已有源注释的筛选及部分边缘案例复核，没有重新观看 400 段源视频，也没有完成人工逐帧审核。`human_review_complete` 保持 false。场景类别和取景特征是透明词表代理，存在语义漏检；原始来源、全部 prompt 和排序细节可供后续核查。核心集文本平均约 483 个英文空白分词，不是模型 tokenizer token 数；优先级筛选不替代模型专用 prompt 适配。
