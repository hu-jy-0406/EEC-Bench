原版、C、C + 插件在 1,000 个视频上的结果

前 200 个 episode × 5 个模型，共 1,000 个视频，每个视频都跑完了三个版本。原版 v3 是现有流水线（11-09 的重跑）；C 在前端补全背景物体，并加了 W8/X10 两个检查项；C + 插件在 C 之上加了 unspecified 专属分支（U1–U3），它的发现和 C 的 V-V 候选合并在一起复核。三版都用逐镜头公式打分。

  • V-V 问题里涉及 unspecified 实体的比例：1.77% → 3.75% → 8.19%。V-L 问题三版都是 0 条，因为 V-L 只检查 contract 写到的实体。
  • 完整流程费用：USD 53.23 → 70.32 → 88.08（标准价估算，不是账单），每个视频 0.053 → 0.070 → 0.088。
  • UEC 平均分几乎不变（81.96 / 81.54 / 81.47），五个模型的排序在三版里完全一样。
  • 新增的 unspecified 问题是"被确认"的数量，是否属实还没有核查，准确率未知。

"确认"按合并复核后的问题单元计：一个单元只要包含插件的候选就算插件的。插件的候选有时会和 C 的候选合并成一条，所以 C + 插件的 V-V 总数（3,213）比 C（3,121）只多 92 条，少于插件确认的 167 条。

C + 插件沿用 C 的 V-L 复核，所以两者的 V-L 问题数相同。

合并复核的波动

C + 插件把 C 的候选和插件的候选放在一起重新复核。在分组和 C 自己那次完全相同的 4,204 个问题单元里，有 931 个（22.1%）判定变了，而且两个方向几乎一样多。这说明差异主要来自复核本身的随机性，看不出是插件造成的。
