# Gs static-set consistency v1.3

## 当前坐标设定（2026-09-16 更新）

后续静态图与跨 shot 对齐遵循 [Shot 固定场景坐标契约 v1](shot-scene-coordinate-contract-v1.md)：每 shot 一个固定场景系，逐帧相机位姿可变；先补偿运镜并统一尺度，再判动静与融合；跨 shot 最终输出到 Shot1 场景系。中心 + 小权重方向拟合设定保持不变。

这是当前设计约定，**逐帧运镜位姿与新融合入口尚未实现，也没有重跑旧结果**。下文“实际执行阶段”记录已实现的 v1.3 流程与历史实验，并不表示旧脚本已具备上述运镜支持。

## 评测对象与唯一扣分入口

每个 shot 已独立完成实体发现、动静分类与静态图生成。令两个冻结静态集合为 S_a、S_b。交集和差集都必须经过跨 shot 身份对应确定，不能对本地 ID 直接做集合运算。

仅允许两类罚分：

1. 静态集合不相交部分：排除动静状态切换、视角/遮挡、剧情许可及检测遗漏后，有原帧证据支持的异常单侧存在。
2. 静态集合相交部分：同一实体对有证据支持的空间关系冲突，并且剧情要求相应关系延续。

身份不明、粒度不一致、几何或映射证据不足保持未知。不添加独立的外观或形状罚分。纯运动实体不进入评分集合。

## 相对 v1.2 的修正

| 事项 | v1.2 | v1.3 |
|---|---|---|
| 静止/运动跨 shot 切换 | 缺少完整辅助动静记录和明确分支 | 用对侧冻结 moving 记录及身份/原帧证明，免罚 |
| 剧情许可 | 默认静态布置应延续，未提供逐实体 Prompt 推断阶段 | 模型在冲突判断前，结合所有静态实体组与剧情推断存在及布局延续要求 |
| 单侧缺失原因 | 主要互补、冲突、未知 | 明确区分 motion_transition / viewpoint / story / inconsistent / detection_gap / unknown |
| 共同实体 | 原规则允许 layout/shape 等单实体机制 | 只允许共同静态实体之间的空间关系罚分 |
| 空间关系分母 | 主要验证反转候选，不能作为完整关系分数 | 先枚举全部共同静态实体对，逐对保存相容、冲突、剧情免罚或未知 |
| 输出 | 参与冲突的实体合并计分 | 保留合并实体分，并另报存在性实体分及空间关系对分，明确不同计量单位 |

v1.3 是新入口；旧版本及已发布冻结文件不覆盖。

## 实际执行阶段

### 0. 冻结输入

- 两个既有静态 Gs、所有原始关键帧、逐帧 2D 框与几何信息。
- 两个 shot 的完整实体记录及之前独立生成的动静标签，仅作为辅助证据。
- 全部相关剧情 Prompt，包括中间 shot 的情节，用于解释合理存在或布局变化。
- 检查哈希及静态节点集合和动静标签严格一致。不得重新保存 JPEG、重判动静、添加节点或反向优化几何以改善得分。

### 1. 静态集合身份对应：一次新 Codex 调用

两个静态图和原始帧，输出严格 matched、单侧 unmatched、ambiguous、scope_mismatch 分区。全部静态节点恰好出现一次。选取可以独立建立物理方向的稳定参考候选。无需共同静态集合完全相等，不按未对齐的坐标最近邻强行匹配。

### 2. 剧情延续要求：一次新 Codex 调用

输入全部静态实体组名称与对应、剧情事实；不给原帧、跨 shot 几何差异、旧判决或异常标签。对每个实体组独立输出：

- presence: persist / change_allowed / unknown。
- layout: stable / change_allowed / unknown。
- 支持的 Prompt 事实编号、允许改变的范围、推理依据。

所有自生成实体均被覆盖，不能把 Prompt 未提及当成任意变化的许可。允许变化必须引用具体情节。相应分数所观察到的缺失或移动不能用作自身合法性的依据。

对于刻意生成错误的测试材料，生成 Prompt 可能含答案和错误制作说明。这些内容不能送给评分模型。本次 Study2 先从来源中逐字提取正常剧情条款，保存原始文档哈希和字符跨度；这是一次有记录的输入整理，不是已经实现的自动剧情清洗模型。生产使用需明确区分剧情要求和测试答案/缺陷注入指令。

### 3. 固定比较机会与数值诊断

- 所有 unmatched 进入单侧原因分支；身份/粒度未解决组保留未知。
- 所有 matched 的无序实体对进入共同静态空间分支，不能只选择有数值反转的关系。
- 使用既有 v1.2 的两参考物加重力局部方向和多帧几何压力范围计算中心顺序。参考物要求模型认为稳定；测试端点不能同时充当本项参考。
- 压力参数保持中心半径 0.25×框对角线、水平轴 ±15°、归一化区间间距 0.005。它们仍是启发式范围。
- 不使用前一轮整图长边拟合，也不要求全房间完成一个变换。数值异常只是候选。

### 4. 不相交部分：两个新 Codex 上下文独立核查

两个审核接收同样的静态图、完整辅助实体/动静记录、剧情延续要求及原帧，彼此看不到结论。

| 原因 | 必须具备的证据 | 结果 |
|---|---|---|
| motion_transition | 确认对侧同一物体，且冻结标签确为 moving；两侧原帧佐证 | 免罚，运动合理性不属于本静态集合指标 |
| viewpoint | 独立空间对应证明诊断区域在对侧画外或被遮挡 | 免罚 |
| story | 事先的逐实体剧情规则允许这个存在变化，且适用于本实体 | 免罚 |
| inconsistent | 存在应延续，源侧至少一帧、目标至少两帧证明可观察位置的异常缺失/出现；排除上述解释、漏检与其他映射 | 扣分 |
| detection_gap | 原帧可能有物体但冻结前端漏检或漏纳入静态图 | 未知，不罚，不添加节点 |
| unknown | 其他证据缺口或审核分歧 | 未知，不罚 |

单侧异常证明的是可比较区域内的存在性/占位不延续，不声称整个未观察房间不存在该物体。

### 5. 相交部分：两个新 Codex 上下文独立核查

逐对判断有向中心顺序、支撑关系或可验证的相对位置。兼容也必须有正面原帧证据，不以无数值反转替代。

扣分条件：两端都是共同静态实体，相关布局应延续，两侧各至少两帧，至少两个不包含被测端点的稳定参考，排除视角和几何误差解释。顺序反转还必须引用本项有效数值候选。其他位置/支撑变化需要直接原帧及物理参照证据；仅有框残差或外观变化不算空间冲突。

两审核的冲突机制和参照必须相容；顺序反转需共享至少一个数值关系依据。分歧转未知，不靠反复重试获取预期标签。

### 6. 确定性计分与审计

代码验证覆盖、引用帧与像素框、静态范围、免罚资格、叙事规则、参考独立性及审核一致性。

主分数维持实体单位：K 为两条合法扣分入口涉及的实体组权重并集。每个实体只计一次，单侧入口与共同实体入口在集合上互斥。关系反转涉及两个端点，不证明两个物体都移动。

`S = 100 × (1 − K / (C + K + U))`；免罚 E 排除在分母之外。报告覆盖率 `(C+K)/(C+K+U)` 与逻辑区间 `[100C/N, 100(C+U)/N]`。没有可判定项时主分数为 null。未知不给罚分，也不是已确认相容。

共同实体仅当所有预先枚举的相关实体对都已判相容或免罚、且至少有一个相容时，主表才记为相容。任一关系未知使其保持未知；有确认冲突则记冲突。

分项：存在性采用同一实体单位，共同静态身份已证明两侧存在；空间分采用共同静态实体对单位，每对最多罚一次。两个分项单位不同，不能直接相加。宽泛地枚举实体对会产生大量未知，需把范围和覆盖率一并报告。

## 运行与验证

入口：`scripts/run_static_set_consistency.py`；确定性门控：`scripts/score_static_set_consistency.py`；契约：`scripts/static_set_contract.py`。

需指定 `--source-run`（提供冻结 Gs 和来源）、`--motion-a`、`--motion-b`、`--narrative`、`--out`。`--resume` 只复用输入完全相同的成功调用，不隐式重试失败推断。每分支两次审核顺序执行，共六个新上下文，采用既有配置的 Codex 服务。

`tests/test_static_set_consistency.py` 覆盖静止到运动、剧情/视角解释、漏检、未知、非法运动计分、形状越界、循环参考、无效数值候选、同帧重复、评测分母完整性等。

这验证了两条扣分入口与用户范围一致；真实判断可靠性仍依赖实体对应、单目几何和模型视觉核查，尚未通过独立人工标注集校准。
