# 200 episode 视频生成 API 费用与工期调研

查询日期：2026-09-22。仅公开资料调研，没有调用视频生成 API、上传数据或启动评测。本表是指定服务入口公开单价的算术估计，不是账单，也不是全市场最低价。

## 工作量与范围

依据 `EECBench/experiments/source_video_priority_20260921/REPORT.md`，Priority200 为120条4镜头、60条6镜头、20条8镜头，共1000镜头。计划每镜头5秒，共5000秒（83.33分钟），平均每episode25秒。20/30/40秒是生成目标，不是所有源视频的实测时长。

以下只计算一次采样的视频生成费用；不含后续EEC评测、税费、存储、参考素材生成和额外视频输入。各模型分辨率、音频及接口不同，不是完全同规格质量比较。无质量择优重抽假设。

## 多镜头适配决定评测含义

- Kling3.0支持`multi_prompt`逐镜头prompt和时长，但单次总长最多15秒。按每镜头5秒，可打包最多3镜头；4/6/8镜头episode分别至少2/2/3次请求，全200条至少420次。打包之间没有自动获得StoryMem式记忆；是否使用生成参考图/视频应单独冻结协议。
- [Seedance2.5官方规格](https://docs.byteplus.com/en/docs/Byteplus_LAS/video_gen_enhanced)支持4–30秒。时长上120条20秒和60条30秒episode可单次容纳，20条40秒需分段，理论至少220次。这仅是时长可行性，不证明模型能准确服从4/6镜头硬切、各5秒和长prompt。实际服务入口应再核验相同能力与文本限制。
- [Kling接口规格](https://fal.ai/models/fal-ai/kling-video/v3/pro/text-to-video/api)提供显式分镜结构，Seedance长视频的分镜精确性需要小样本检验。不要为塞进15/30秒而直接压缩原episode所有镜头时长。
- 逐镜头独立T2V易于统一为1000次请求，但测量的是该独立生成协议下的一致性，不能称为模型原生episode记忆能力。
- 不使用源视频/源帧作为额外生成参考来无意改变纯文本任务；若使用模型自己的已生成素材，应标清为另一生成协议。

## 耗时：情景估计，不是实测

稳态近似：总分钟 ≈ 请求数 × 平均占用并发槽分钟 / 有效并发。另受排队、RPM、每日配额、账号预算、串行依赖和下载验证限制。提交请求不等于占用真实生成槽位。

对1000次独立短片请求，假设每次平均2–10分钟：

| 有效并发 | 理想生成时间 |
|---:|---:|
| 2 | 16.7–83.3小时 |
| 5 | 6.7–33.3小时 |
| 10 | 3.3–16.7小时 |
| 20 | 1.7–8.3小时 |

这里的2–10分钟是敏感性分析输入，不是对Kling/Seedance/Runway延迟的官方断言。对长片打包应重测L，不能因请求数从1000降到220便声称快4.5倍。例：220请求、每次10分钟、并发5约7.33小时；这是计算例，不是速度承诺。

[Google文档](https://ai.google.dev/gemini-api/docs/veo)给出Veo请求11秒至高峰6分钟的范围；它不是本数据平均值。[Runway账号等级](https://docs.dev.runwayml.com/usage/tiers/)同时约束并发、每日生成次数和月花费：Tier3并发5、月花费上限2000 USD，累计购买100 USD后立即可达；Tier4并发10、累计购买1000 USD后立即可达。充值是账户余额，不是额外模型费用。不同模型每日额度需查看实际控制台；不能将页面教学例子“每条15秒”当Gen-4.5性能测量。

因此若能落实5–10有效并发，可先安排半天至两天的执行窗口；若只有1–2并发、每日限额很低或上游拥堵，可能数日。账号开通/提额等待另计。当前没有登录供应商核验本账号额度，也没有实测网络可达性或吞吐。

## 选择建议与最小校准

预算优先且需要显式multi-shot输入：优先试Kling3.0 Pro，静音基础560 USD，留至约670 USD；分段协议需明确。整段叙事/减少episode拆分优先：试Seedance2.5，已核实的Runway入口480p/720p预算含20%约1200/1800 USD，同时核验BytePlus直连能否降低价格。Veo3.1 Fast可作为600 USD左右的另一家闭源基线，但5秒任务不直接匹配。

建议固定挑6条pilot（4/6/8镜头各2条，共36镜头、180目标秒），测成功率、实际账单、排队/生成时间、有效并发、镜头数量/顺序和prompt截断；不按评测得分挑选结果。静音Kling约20.16 USD；Runway托管Seedance2.5约36/54 USD（480p/720p，无视频参考）；VeoFast按36×6秒约21.60 USD。pilot通过后冻结model/version/入口/音频/分辨率/生成协议与失败重试规则，再扩展200条。

本轮没有付费视频生成调用，没有修改当前Wan/StoryMem/HoloCine任务或评分协议。
