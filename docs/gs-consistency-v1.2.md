# Gs consistency v1.2：加入空间关系冲突

v1.1 对本例确认了台灯旧占位消失、纸巾新占位出现，但杯子与笔筒的布局变化仍为未知。v1.2 在固定 Gs、实体对应和存在性结果上，增加有几何证据和原帧证据的局部空间关系检查。

## 通用规则

1. 从已对应且允许作参考物的实体中取参考对 k、l；两个待比较实体 i、j 均不能同时作该关系的参考物。当前 Gs 格式约定世界 z 向上。
2. 在每个 shot 内，用参考物中心的水平连线得到 v=normalize(horizontal(c_l−c_k))，再算 u=v×z；局部右手坐标系 B=[u,v,z]，基线 L=‖horizontal(c_l−c_k)‖。零基线无效。
3. 比较有向中心关系 r_ij,d=(c_i−c_j)·d/L，d∈{u,v,z}。正负号描述同一物理参考方向上的中心顺序，不是原帧的左右。平移消去，正尺度消去；坐标系适当旋转且物理向上方向同步旋转时该关系不变。它能发现单看两物体距离无法发现的顺序反转。
4. 使用融合 Gs 及共同选中的可见帧几何，枚举端点估计与参考估计的组合，至少有两帧支持。每个端点中心的水平扰动半径取其水平 OBB 对角线的 25%，参考方向容差取 ±15°，求联合区间；竖直轴的中心扰动半径保守地使用三维框对角线的 25%。两 shot 区间必须严格异号，且区间间距超过归一化基线的 0.005，才成为数值候选。这些是可检查的启发式压力范围，**不是统计置信区间**。
5. 两个新建、互相隔离的 Codex CLI 上下文分别读取本 shot 的 Gs、全部六张原帧和参考方向，先为所有匹配的非参考实体判断支撑物，再枚举与参考原点具有共同支撑的实体对，判断各轴中心顺序与依据。每个上下文不知道另一个 shot 的数据、旧判断或预期异常。
6. 保留两侧都验证共同支撑的关系。对数值候选再调用一次跨 shot Codex 原帧复核，检查身份、参考物、共同支撑、参考方向对应、中心语义、几何误差与纯视角解释。单 shot 观测必须各有至少两帧依据、方向与数值一致、没有可逆转顺序的几何歧义；复核同样要求两侧各至少两帧和全部条件通过。任一条件未过，保持未知，不扣分。

程序没有杯子、笔筒等类别特例，也不接收预期错误清单。几何候选由程序计算，支撑物/实体身份/原帧中心与遮挡证据仍由 Codex 判断。多个上下文使用同一模型，不能将其同意解释为独立的统计置信度。

## 评分

沿用原有实体权重。令 P 是存在性等旧规则确认冲突的实体组集合，R 是通过上述检查的空间冲突关系集合。新的冲突集合为 P 与 R 中所有端点实体组的并集；同一实体即使参与多条关系、多种冲突也只计一次。

K = 该并集中各实体组权重之和。

S = 100 × (1 − K / (C+K+U))。

C/K/U 分别是相容/确认冲突/未知实体权重；互补 V 排除在分母外、也不罚分。本例所有实体组权重均为 1。一条杯子—笔筒关系反转新增两个参与冲突的实体单位。这度量的是**参与不相容结构的实体范围**，不证明两个物体都移动，也不判定哪一个造成错误。未知不扣分，主分数因此是上界；必须同时报告覆盖率 (C+K)/(C+K+U) 与区间 [100C/N,100(C+U)/N]。没有可判定项时主分数为 null。

## 当前覆盖范围和限制

这是局部参考方向对应，**没有完成全房间空间配准**。当前新增检查覆盖共同支撑区域、参考方向可靠的有向中心关系；距离变化、支撑变化、尺寸变化和无共同参考的其他关系还不能保证检出，不应把未评估项当成相容或互补。参考物本身变化、共同几何偏差和模型视觉误判仍可能影响结果。

当前阈值在这个开发样例上迭代过，未经过独立数据集标定；不能以该样例的成功宣称跨场景准确率。早期原型将 0.005 分别用作两侧距零阈值，生产版本改为两区间的分离裕量，正负顺序另外严格检查。最终设置在这三次正式取证调用前确定。敏感性表保留完整的中心扰动比例 {0,0.125,0.25,0.5} × 方向容差 {0°,15°,30°,45°} 结果；不只展示通过设置。

## 运行与回放

在账户已有、CPU 空闲的 Slurm 计算节点上执行；不需要 GPU。

```bash
python EECBench/scripts/run_gs_spatial_consistency.py \
  --source-run <完成的_v1.1_结果目录> --out <新目录>
python EECBench/scripts/audit_gs_spatial_consistency.py <新目录>
python EECBench/scripts/render_gs_spatial_evidence.py <新目录>
```

上述首条会产生两个独立单 shot 调用，以及有候选时的一次跨 shot 复核。仅回放既有证据、不调用模型：

```bash
python EECBench/scripts/replay_gs_spatial_consistency.py <结果目录>
```

冻结版本 `releases/gs-consistency-v1.2` 包含源码依赖闭包、提示词、输入、原始模型取证、分数、审计和可离线查看的 12 帧证据网页。回放使用冻结 payload 中的 scripts 和结果目录，不依赖原始绝对路径或在线模型。重新模型推断仍需要工作区原图；模型输出本身不保证逐次相同。
