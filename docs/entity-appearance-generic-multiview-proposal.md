# 通用实体多视角外观评价（方案 v3，待选定）

2026-09-20 用户纠正：人物只是例子，方法必须适用于各种物体。此文件取代v2中以人物front/side/back为核心的参考分组及R<=3调用量说明。通用原则采用可见表面、物理部位及可比较属性；人物是其中一个实例。仍为设计方案，未修改生产prompt/代码/评分门槛，未运行模型。

## 评价对象

对于已冻结身份的global实体，不要求不同视角的二维外观相同，而是判断各观察能否由同一个外观保持不变的物体在不同视角、光照和合理形变下产生。不能用“可能是另一面”自动解释掉异常；也不能把未观察到的表面填成一致。只判断输入关键帧展示的内容，不生成规范视图或幻觉表面作为证据。

## 1. 通用可见性描述

每个appearance由Codex在shot局部原帧/原框中描述：可见语义部位/表面，裁切、遮挡、投影形变和证据质量。视角只是辅助描述（斜上、侧向、内侧、无法确定等），不强制物体具有front/side/back。没有语义部件的石头、水果等使用可定位表面patch、轮廓段和纹理区域。集合实体使用整体轮廓、可见成员及其属性，不强行建立成员ID。

记录数据结构：appearance_id、visible_regions[{local_region_id, semantic_part_or_surface, source_frame_bbox_or_region, observability, evidence}]。这些是辅助证据定位，不替换canonical检测框，不增加实体节点；若未来需部件定位框，必须保存独立的证据坐标与出处。

同一部位名称不保证物理对应：两张图各自叫“左桌腿”可能是不同桌腿，两张图的“侧面”也可能是相反表面。各shot独立描述后，比较阶段需要明确physical_region_correspondence及其证据；不按同名直接配对。二维bbox和独立图像描述不能保证此对应。现有3D/相机估计只有可靠时可作辅助，不强依赖重建，也不把不可靠配准当真值。

## 2. 固定的可见表面参考集与比较清单

不用DINO聚类来定义视角组：真正变色或换形也会分裂latent。按原图中可见部位/表面的重叠关系组织少量参考，目的是覆盖已观察视域，非“每种外观模式各选一个正常模板”。

以最早清楚且范围正确的真实appearance为首个参考；只有出现此前未覆盖、可清楚描述的新表面时，才添加新的候选参考。仅因颜色/纹理/结构不同不得增建参考或重置基线。用时间、画面质量和可见区域覆盖固定选择与预算，评分前冻结。新参考本身仍必须接受与已有参考的可比部位检查，不自动赋满分。若无法确认是否新表面，保持unknown，不借此逃避比较。

为所有appearance选择共同可见区域最充分的参考；如不同属性需要不同参考，允许少量固定补充。路由不得使用实际一致性分数或最大DINO相似度。目标自身不得当参考。参考之间也需要固定比较边，包括有共同表面的边和相邻新视域的连接检查。参考数R随实体视域复杂度而变，不再宣称恒定3或约N次：若每目标至多K个参考、参考图有E_R条边，比较上界K(N-R)+E_R；参考全连接时E_R=R(R-1)/2。预算导致未覆盖区域必须显式保留，不静默跳过appearance。

纯novel-view、重复/对称结构、弱重叠、遮挡等都允许形成未连接的证据组。若各组内稳定但组间无法比较，只能报告组内稳定，不声称整个实体跨视角已验证。

## 3. Codex按具体可见属性比较

通用流程：先验证物理部位/表面对应，再判断该区域有哪些属性在两边可观察，最后判差异及原因。编码器低相似度不作为变化证据，也不作为唯一调用门槛。通用属性类型是：

- 结构与部件：连接、孔洞、把手、支撑等；允许投影形状变化，不要求2D轮廓相同。
- 表面外观：同一表面的颜色、纹理、材料可见特征；异面不同颜色/图案不自动冲突。
- 内在比例：同一对应部件间的可辨关系；不以像素大小、角度相关宽度或遮挡长度评分。
- 独特细节：logo、划痕、饰边、花纹等必须处于同一可见表面。

不能观测的物理性质不得从视觉过度断言。透明/反光、柔性形变、铰接开合、液体内容变化尤其要区分表面/光照/状态；剧情解释只豁免有依据的维度和时间。

判断输出：region_correspondence={supported,unknown}、共同证据、逐属性score(1–10/null)、status={consistent,conflict,unknown,expected_change}、解释与原图定位。视角差異只有在原图证据支持时才能解释改变；未排除合理替代解释则unknown，不能一律判一致。

## 4. 类别示例

- 杯子：一侧有把手、背侧看不见，不是部件消失；需要可见几何/遮挡证据。杯口/杯身同一可见表面可以比较。正面logo与背面空白不可直接比较。
- 椅子/桌子：不同观察中露出的腿数可能不同；可比同一连接处、靠背构造与可见表面。不能把图像左腿直接映射到另图左腿。
- 台灯：圆灯罩侧看椭圆可由投影解释；同一个可见灯罩表面发生明确且光照不能解释的颜色改变才是冲突。
- 盒子/包装：正面彩印、背面文字是不同表面；同面logo变形/消失且无遮挡可判断异常。
- 球体/水果/石头：不同角度可见不同斑点，需同一patch或形状证据；纹理极少的球可能只能评价少量总体属性。
- 笔组/橘子堆：视角/遮挡引起可见成员数量不同不等于真实数量变化；比较集合范围一致的可见材料、形态、成员类型等。精确数量/单成员身份无证据则unknown；成员框不能冒充整组框。
- 人物：面部、头发、衣服等是通用部位的实例；正背面不自动扣分，脸不见不自动一致。

## 5. 原始多视角witness与评分

源/目标shot中的额外真实关键帧可提供逐渐露出表面的过程。不得生成或3D渲染未观测表面当证据；不得把跨不同属性的“相容链”当成所有属性一致的证明。辅助帧不重复计样本。

DINO原中心分数保留，VLM承担对视角/可见性/真实外观变化的解释。VLM按冻结比较清单在可判属性上评分，并保留足够重叠比较、跨不同视域比较的分项与有效/未知/失败/合理变化数量；v2的same_view/cross_view标签只能作为展示，不再用人物三个角度硬分类。维度/shot对等权聚合的选择仍待校准，不新增任意DINO+VLM融合。清楚报告结论只覆盖哪些表面与属性；跨视域完全不可比时返回null，不能因没有确认异常而给100。
