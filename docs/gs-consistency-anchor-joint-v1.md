# 参照先行、身份与存在性合并判断：实验分支 v1

版本：`anchor_then_joint_presence_v1`。旧版 `post_alignment_identity_review_v1` 的代码、配置、实验结果保留；本分支独立测试，未替换默认流程。

## 顺序

1. 原始 JPEG 全帧 WeDetect → 每 shot 独立 Codex 聚类。
2. 每 shot 独立 GeoCalib、Pi3X 多帧相机/深度、逐帧深度约束 Boxer；独立 Codex 动静判断，融合固定静态框并保存运动轨迹。
3. **只对应配准参照实体**：新 Codex 上下文根据原帧、静态清单和观测，选出少量确认同身份的稳定结构/大型家具，并选局部支撑参照对。未选实体仍是“尚未对应”，不能解释为单侧或缺失。
4. RoMa 全部关键帧组合、结构区域/置信度/循环一致性筛选、逐帧深度提升、重力约束正尺度+yaw+平移配准。保持已有算法及阈值。
5. **一次联合判断完整身份和存在性**：一个新 Codex 上下文看到全部原帧、各实体的本地/对齐融合框、对侧相机投影、融合不确定性、逐帧2D观测、全部动静实体清单、配准质量和正常剧情。此时没有非参照实体的先验完整匹配，也不输入历史结论、cosine 或预期异常。输出全静态实体守恒分组、每组存在性分类及原帧/Prompt证据、对配准参照的核验。
6. 对身份已确认且共同出现合理的全部无序实体对算 cosine；负值进入两个独立单 shot 局部取证，再按原有支撑/参考端点门筛查，最后做跨 shot 原帧和 Prompt 运动复核。
7. 输出存在性、空间关系两个分数与各阶段实际时间/token。

## 联合判定的证据门

非共同静态实体的原因类别严格为 viewpoint / motion / inconsistency；不确定、漏检或证据缺失是 unknown 状态，不引入新语义类别。共同实体只检查“应离开场景却仍出现”，否则需有两侧正面存在证据才能进入空间比较。Prompt 未提到的自生成实体仍需结合场景和剧情判断。

取消双判断共识，保留旧版单条判定的证据门：冲突要求每 shot 至少两帧像素证据、全部可观测/遮挡/漏检/身份/位置门及明确 Prompt 因果复核；compatible 要求两侧存在证据与 Prompt 依据；豁免要求具体视角/运动证据与 Prompt 依据。未通过门的结论变成 unknown；unknown 不扣分，仍在分母中。一次模型输出不能绕过这些确定性校验。

不按大坐标差直接拆身份；需排除同一物体真实移动的解释。不同实例也不自动免罚，仍需单独证明视角或运动原因。

## 参照失效处理

联合判断若推翻某配准参照：原有效匹配点贡献为0时，记录移除而保留变换；若贡献非0，归档该轮结果，移除失效参照，用**同一本轮新生成的原始 RoMa 匹配点**重新筛点/配准，并用全新上下文重新联合判断，不提供上一轮结论。循环每次至少移除一个参照，次数由初始参照数限定。参照不足则不把不完整流程报告为已完成或空间100分。

## 输入与消耗记录

两个新阶段只发送各自任务所需的观测：参照选择不携带存在性分类，联合判断只保留一份原始/对齐融合框、2D观测和辅助动静清单，不再次追加整套逐帧3D图。空间复核的既有输入格式保持不变。

实验实现：`EECBench/experiments/study2_anchor_joint_fresh_20260918/`。分阶段入口 `run_frontend.py`、`run_backend.py`；`evaluate.py` 只开放 anchors / joint / spatial；`anchor_joint_contract.py` 校验实体守恒、原帧证据、Prompt和参照回退。每个 Codex 调用保存 request/input/response/events/status，所有实际调用与回退均计时计token。旧结果只在最终报告中用作对比，不进入新模型调用。

同一案例的两次完整重跑会包含模型输出和运行环境波动；时间差不是固定加速比，单次成功也不构成准确率或稳定性结论。
