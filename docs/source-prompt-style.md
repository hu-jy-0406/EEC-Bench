# 源视频到逐镜头 prompt：写作偏好

用户明确要求（2026-09-20）：认可当前样例的整体描述方式；逐 shot prompt 适当增加镜头/机位描述，但不要每个 shot 都增加，以保留 prompt 多样性。

执行原则：

- 选择性描述景别、机位高度/角度、构图或运镜；只加入有来源证据且对目标画面有帮助的信息。
- 一部分 shot 以人物、动作、场景为主；另一部分明确镜头要求。细节多少和句式随内容变化，不统一套摄影术语开头。
- 不规定固定添加比例，不为凑多样性虚构运镜；机位/景别可由画面支持，运镜需连续时间证据。
- 下一版提取提示词应将试验版逐 shot 一律要求 framing 的表述改为上述选择性规则。旧试验的提示词快照和已生成结果保留原样。

本次反馈确认的是构造风格；没有新增付费提取，也不将其记为全部源事实已人工核验。评测器提示词和评分规则不受本偏好影响。
