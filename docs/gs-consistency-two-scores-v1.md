# 跨 shot 静态一致性：双分数流程 v1

当前采用流程1：完整初始身份对应与参照选择 → 场景配准 → 逐组身份复核 → 一次存在性判断 → 空间关系评测。执行入口与规则见 [Flow1 skill](../skills/gs-consistency-flow1/SKILL.md) 和 [配置](../configs/gs-consistency-two-scores.v1.json)。流程2保留为独立实验方案，默认不启用；本页后半的历史实验记录保持其原始口径。

从原始 JPEG 到单次 B 分类的统一入口与数据衔接见[整合流程](gs-integrated-flow1.md)。

## 1. 两个输出分数

| 分数 | 计量单位 | 扣分对象 |
|---|---|---|
| 静止实体跨 shot 一致性 | 跨 shot 身份实体组 | 应出现却异常缺失／新增；应离开场景却仍出现 |
| 实体空间关系一致性 | 应共同出现的共同静态实体无序对 | 负 cosine 候选经原帧筛选和复核确认的方向／顺序冲突 |

同一实体组在第一分中最多计一次；同一实体对在第二分中最多计一次，多个方向反转不重复扣。同一实体可参加不同实体对，各对是不同空间关系。两个分数单位不同，分别报告，不合并成单一总分。杯子—笔筒只计一对空间冲突，不分别罚两个端点。

“应离开场景却仍出现”属于第一分；仅需换位置而没有换位置不属于存在性冲突，应归空间语义。但当前第二分只用负 cosine 生成方向冲突候选，不能保证检出所有未执行移动、距离或尺寸变化，不为这些情况自动增加新检测阶段。

## 2. 每个 shot 独立建图

每个 shot 独立完成下列过程，后一个 shot 的图片、实体、几何、标签和跨 shot 判断均不能进入本 shot 上下文。

1. 对全部提供的原始关键帧运行 WeDetect-Anything；保留每个 proposal 和过滤原因。继续使用原始 JPEG，不能为复用实验擅自重新编码。
2. 新鲜 Codex 上下文仅根据本 shot 检测与图像返回命名候选簇和拒绝项。程序按置信度及候选ID选择原始检测框，派生逐帧记录；无框时存在性未知。无检测候选不添加实体，不补框或修框。
3. 用本 shot 多帧估计固定场景系及每帧完整 camera-to-scene 位姿、内参、深度，构建逐帧 3D 实体图。当前已测试模块为 Pi3X + 深度点云条件 Boxer；原始尺度来自模型而非实测标定。
4. 把每帧框转换到该 shot 的固定场景坐标系，补偿相机运动后，再在独立新鲜上下文中判断静止／运动。相机缓慢运镜不等于实体运动。
5. 静止实体的有效逐帧框融合成 shot 级静态图；运动实体保留最佳可见帧代表框和逐帧轨迹，作为下游辅助证据。动静不明保留未知，不强制归静态。

产物：完整实体表、检测与聚类证据、逐帧相机和实体框、独立动静标签、静态 shot 图、运动轨迹、原图哈希。固定坐标约定见 [场景坐标契约](shot-scene-coordinate-contract-v1.md)。

## 3. 跨 shot 只按用户定义划分共同与非共同出现

输入是属于同一场景的两个 shot 各自的冻结静态集合。由模型结合实体和原帧确认身份，划分为**共同出现**与**非共同出现**两部分。本地ID不同不代表不同实体，未经验证的空间最近邻不能强行确定身份。身份不明或粒度不匹配保留待定记录，不强行塞入某一部分。

不再先给所有实体划分“保留／离开／允许变化”等通用政策类别，也不单独增加这样的分类阶段。Prompt 是下面每一项实际原因判定与最终冲突复核的依据，包括相关中间 shot 的动作要求。所有已发现实体都进入对应流程；自生成、Prompt 未点名的实体不能被直接视为可任意改变。

### 3.1 对齐后的身份复核（2026-09-18 新增）

实际执行顺序为：单shot建图 → 初次身份对应 → 按原结构区域筛选RoMa匹配并求场景变换 → **对齐后身份复核** → 存在性判断 → 建立空间关系总体、计算cosine与复核。先得到初次匹配以供原配准筛选使用；下游两个分数使用复核后的身份组。

新的独立Codex调用读取全部原帧、冻结静态清单、初次对应假设、统一Shot1场景下的框和中心差异、逐帧对侧投影诊断、原配准质量以及正常剧情Prompt。对所有原身份组记录保留／拆分／重配／待定及原帧证据，而不是只审查负cosine。

- 大坐标差异触发仔细核对，但不能单独强制拆分；需排除模型几何/配准误差与同一物体真实移动。真实发生位置变化但身份明确的实体仍保留对应，交由后续空间评估。
- 相似类别、重复画作、类似植株不等于同一物理实例。支撑家具的身份被推翻时，独立复查其上物体的身份依据。
- 拆分后每个原实体恰好进入一个最终组，不增删或合并单shot实体。只有原帧和相机/场景环境证据支持对侧不可见，才建议视角原因；拆分本身不等于视角豁免。
- 身份证据不够保留unknown；不同视角、运动、不一致仍是非共同出现的三种原因，类别和计分规则不变。下游一次存在性判断核实原因和Prompt，通过原帧与Prompt证据检查后采纳；检查失败或身份未定则保留unknown。
- 冻结原变换，不因复核后的身份结果循环重拟合。被否定的结构锚点从修正清单移除，记录其原拟合参与量和对配准可信度的影响。若局部支撑参照身份失效，则关系复核保持未知，不偷偷沿用失效参照。
- 保留 `matching_initial.json`、复核请求/响应、逐组变更和新 `matching.json`。既有冻结实验不覆盖；重算受分组影响的分母和全部空间对。

实现：[复核模块](../scripts/review_aligned_entity_identities.py)、[提示词](../prompts/gs_aligned_identity_review_v1.txt)。本阶段版本标识 `post_alignment_identity_review_v1`，配置的双分数主版本仍为v1。

## 4. 第一分：静止实体跨 shot 一致性

B 阶段只调用一次模型，逐组判定并执行原有证据检查，不再要求第二次判断达成一致。模型输出结构、分类与计分公式不变；聚合结果标记为 `single_presence_witness_v1`。

### 4.1 非共同出现部分：判断具体差异原因

严格采用用户指定的三类：

| 类别 | 要判断的具体情况 | 处理 |
|---|---|---|
| 视角原因 | 对侧因视角、画外或遮挡不可观察，所以只在一边静态集合中出现 | 有证据则免罚 E |
| 运动原因 | 一边静止、另一边运动而不在另一静态集合中；或相关动作造成实体移入／移出，需要结合Prompt、身份和动作证据解释具体差异 | 有证据则免罚 E |
| 不一致原因 | 实际异常缺失／新增；结合原帧、完整动静记录和Prompt，排除合理视角／运动及其他具体剧情解释、检测遗漏后，确认差异不合理 | 第一分记 K，每实体组最多一次 |

无法归因、检测遗漏、身份不明、Prompt解释不清等记未知 U；这是证据状态，不新增语义分类。不能把前两类没有判定成功的剩余项自动当作不一致。没有检测框不等于物理不存在；Prompt也不能仅因出现“运动”字样就解释无关物体消失。

### 4.2 共同出现部分：检查共同出现是否合理

按用户指定的问题判断：**是否有本应离开场景却仍然出现的实体？**

- Prompt及场景证据支持该实体应当离开，而目标shot仍出现：第一分记 K；本项不再衍生空间罚分。
- 共同出现合理：第一分记 C，并进入共同静态实体的空间关系检查。
- 身份、离场要求或出现证据不足：保留 U，不凭空推断该移走。

“该移走”在这里严格指应离开场景／不再出现，不指只需换位置。共同出现合理并不表示位置必须相同；是否由Prompt规定的运动导致位置变化，在空间候选最终复核中具体判断。

## 5. 第二分：实体空间关系一致性

### 5.1 先固定所有关系对

令 M 为身份确认、在两边均静止且共同出现合理的实体集合。预先建立全部无序对 P，共 m(m−1)/2 项。不能按是否数值异常、是否通过支撑筛选或是否容易复核来缩小分母。对包含配准参考物的关系也计算 cosine；是否能复核另行记录。

只有结合Prompt确认其中规定的运动能够解释本项具体位置／方向变化时才记 E。共同支撑不足、配准不可靠、参考物成为端点、看不清等属于证据或方法覆盖缺口，记 U，不能当作剧情免罚或一致。

### 5.2 原图关键点匹配与场景间配准

1. 使用两个 shot 的多张原始关键帧进行跨帧匹配（当前实验为 RoMa v2 全6×6帧对）。
2. 使用稳定环境结构候选区域，排除正在运动或用于待测关系的小物体像素；先选参考再看评分，不能用预期异常来挑配准结果。
3. 每个匹配点用所在关键帧自己的深度与 camera-to-scene 位姿进入其 shot 固定场景系。
4. 用对应点求一个场景间变换 `p_3_to_1 = s R_z(theta) p_3 + t`，联合优化正尺度 s、偏航和三维平移，保持重力方向。当前默认对所有选定三维点对最小化未平方欧氏距离总和，各点等权，优化过程中不筛点、不截断；二维重投影只作诊断。
5. 保存全点及逐结构三维距离、描述性重投影误差；旧train/holdout分区全部参与拟合，不作独立验证。冻结变换，再将全部框转换到 Shot1 固定场景坐标系。允许生成低可信配准下的候选，但不能仅凭它扣分；局部视觉证据可以独立验证特定关系。

两个 shot 的场景系各自固定，逐帧相机仍可以变化。不是把所有关键帧当作同一个相机。

### 5.3 所有实体对计算 cosine，仅负值进入筛选

固定端点顺序，取 `v1 = c_j1 − c_i1`，`v3 = s R(c_j3 − c_i3)`：

`q_ij = dot(v1,v3) / (norm(v1)*norm(v3))`。

平移在差分中抵消，统一正尺度在 cosine 中抵消。零／近零向量或无有效几何时记录不可计算 U。

| 数值 | 动作 | 计分含义 |
|---|---|---|
| q < 0 | 产生一个实体对候选，送后续筛选 | 不是直接罚分；表示估计方向夹角大于90° |
| q >= 0 | 不增加原帧复核环节，不扣分 | 数值检查未触发候选；未验证时记 U，不冒充已验证相容 C |
| 不可计算 | 保存原因，不罚 | U |

“非负不等于已确认一致”只是分数语义与证据覆盖说明，不新增非负候选复核，也不新增距离／尺寸／移动轨迹检查。数值未触发的项目仍保留在评分分母中。

### 5.4 负 cosine 候选的筛选与原帧复核

采用已测试的 v1.2 视觉流程适配，并按用户本次纠正加入最终Prompt运动原因复核：

1. 两个新鲜隔离上下文分别只看本 shot 图、全部原帧和本 shot 可用局部物理参考，判断实体的支撑关系及局部中心顺序。它们不知道对方 shot、候选得分、历史结论或预期错误。
2. 对负 cosine 候选应用共同支撑筛选。参考物不能同时充当本项待测端点。对不满足当前局部复核适用条件的项目保留 U。
3. 对存活候选做跨 shot 原帧复核，每侧至少两帧，检查：身份、参考物、共同支撑、参考方向对应、中心语义、几何误差替代解释和纯视角替代解释。这一步判断数值变化是否对应真实空间变化，尚不能单独决定扣分。
4. **同一次最终复核必须读取相关正常剧情Prompt，检查该位置变化是否能由其中规定的运动影响得到。** 覆盖两个被比较shot及相关中间shot。记录具体条款、动作、作用实体、时间和该动作如何解释此关系的变化；不能仅输出“允许变化”，也不能要求用户提前列出所有自生成实体。
5. Prompt规定的运动足以合理解释该变化：免罚 E。Prompt或因果解释不清：未知 U。确认真实变化、视觉门槛通过，并已排除Prompt规定运动造成该变化的合理解释，才记空间冲突 K。仅两边都静止不能证明中间没有被搬动。
6. 本次方法仍只复核负cosine候选，Prompt复核纳入该候选的最终判定，不增加非负cosine复核。每个实体对最多扣一次。

例如，杯子和笔筒在两个被比较shot内都静止，但中间shot的Prompt规定“把杯子从笔筒一侧放到另一侧”，且足以解释观察到的方向变化，则不扣空间分；只有“人物走到门口”不能自动解释杯子换边。动作若只涉及某实体，也不能无依据地豁免其他实体对。

最终记录必须同时包含 `visual_review` 和 `prompt_motion_review`：后者记录Prompt事实引用、相关运动、受影响实体、因果解释，以及“能解释／不能解释／不确定”的结论。这些是具体候选的复核字段，不是给所有实体另建“保留／离开／允许变化”分类。

桌子—暖气片是当前 Study2 的参照实例，不是所有场景必须有的实体。当前实现的同支撑筛选会遗漏跨支撑关系，所导致的未知必须呈现在覆盖率中，不为提高分数隐藏。

## 6. 两分分别计算

对每个分数独立统计：C=确认相容，K=确认冲突，U=未知，E=具有证据的免罚。单位分别是实体组和实体对，默认等权。

- `N = C + K + U`，E 不进入分母。
- `Score = 100 × (1 − K/N)`。
- `Coverage = (C+K)/N`。
- 未知敏感性区间为 `[100C/N, 100(C+U)/N]`。
- 静止实体分：N=0 或 C+K=0 时 Score=null。
- 空间关系分：完成评测后，K=0 时不扣分，Score=100；包括没有负cosine、有负cosine但未确认冲突，以及没有可计分实体对的情况。K>0 时仍按 `100×(1−K/N)` 计算。候选数、未知项及覆盖率继续保存，不新增复核环节。运行失败或尚未完成不冒充完成评测的100分。

未知在分母中但不罚，因此输出是“只扣确认冲突”的分数上界，不是已证实一致的比例。空间关系只按确认冲突扣分；没有确认冲突即为100，包括负候选未通过复核。证据状态仍可为未知，覆盖率单独报告；不额外复核非负关系。

每条扣分记录：实体或实体对ID、名称、实际违背、用户定义的原因类别、原始帧与区域、数值候选、原帧复核结果、Prompt事实及运动原因复核依据。每分同时报告分子分母、C/K/U/E、覆盖率和范围说明。
